月度 Word 印領清冊 (憑證) 生成教學

請點擊上方「1. 下載當月結算 JSON」按鈕，會下載一個命名為 代課費系統備份_YYYY-MM.json 的檔案。請將該檔案與您本地資料夾下的 generate_voucher.py 放在同一個目錄中。

# 1. 開啟終端機並切換至資料夾
cd "/Users/tsai/Desktop/志益小工具/代課費計算系統"

# 2. 執行 Python 憑證生成腳本
python3 generate_voucher.py

* 執行後，腳本會自動安裝所需套件，並產出一份符合行政核銷規格的 Word 橫式 A4 印領清冊（含表格線條與自動小計）。

Google Sheets Web App 設定

貼上您從 Google 試算表部署取得的 Web App URL。此網址將用來讀取所有老師填報上傳的代課資料。

後端要求金鑰才會回傳代課費資料，避免任何人拿到網址就能抓走全校薪資紀錄。 金鑰只會儲存在這台電腦的瀏覽器，不會寫入本檔案，也不會上傳。
教師端 (teacher.html) 不需要金鑰，老師照常填報即可。
