# 國小代課費計算與管理系統（分享版）

讓老師免登入、用手機就能填「請假代課與交接單」，資料自動寫進 Google 試算表；行政人員月底一鍵彙整，
再用 Python 自動產生代課費印領清冊（Word／Excel）。全部使用免費服務。

> 這是**去識別化的分享版**：所有金鑰、後端網址、教師姓名、校名都已移除或換成佔位字，
> 請依下方步驟換成你自己學校的設定。

## 系統架構

```
老師（手機／電腦，免登入）
   ↓ 填表單送出
teacher.html（可放 GitHub Pages）
   ↓ POST
Google Apps Script 後端（google_apps_script.js）
   ↓ 自動依月份建立「YYYY-MM_總表／明細」分頁
Google 試算表（資料庫，不公開）
   ↑ GET（需金鑰）
admin.html（行政後台，只放本機，不要上網）
   ↓ 下載當月結算 JSON
generate_voucher.py → 印領清冊 .docx / .xlsx
```

| 檔案 | 用途 |
|---|---|
| `index.html` | 入口頁 |
| `teacher.html` | 教師端填報（可自動依課表帶入當天該班科目、列印交接單） |
| `admin.html` | 行政端核銷後台（需金鑰；**只放本機**） |
| `google_apps_script.js` | 後端，貼進 Google 試算表的 Apps Script |
| `generate_voucher.py` | 讀取月結 JSON，產生印領清冊 |
| `sample_Class_Timetables.csv` | **假資料**的課表格式範例 |

## 部署步驟

### 1. 準備試算表
1. 建立新的 Google 試算表。
2. 新增分頁 `Class_Timetables`，第 1 列欄位：`班級`、`星期(1-5)`、`節次`、`科目`、`授課教師`
   （格式請參考 `sample_Class_Timetables.csv`），從第 2 列貼上你學校的課表。
   **換學年只要換這個分頁的內容，不用改程式。**

### 2. 部署 Apps Script
1. 試算表選單「擴充功能 → Apps Script」，把 `google_apps_script.js` 全部貼上。
2. 修改 `SECRET_KEY`：**自訂一串隨機長密碼**（用來保護行政端資料；不要用預設、不要上傳到 GitHub）。
3. 「部署 → 新部署 → 網頁應用程式」：
   - 執行身分：**我**
   - 誰能存取：**所有人**（老師免登入需要）
4. 複製產生的「網頁應用程式 URL」。
5. 之後每次修改程式都要「部署 → 管理部署 → 建立新版本」，否則前端仍是舊邏輯。

### 3. 設定網頁
- `teacher.html`：把 `DEFAULT_GAS_URL` 換成你的 URL（或進網頁右上角設定填入）。
- `admin.html`：同上，並在設定裡填入 `SECRET_KEY`（金鑰只存在瀏覽器，不寫進程式）。
- 把 `HOME_SCHOOL`、頁面中的「○○國小」改成你的校名。
- `NON_REQUESTING_TEACHERS`：填入不需使用本系統的教師姓名（會從下拉選單排除，不影響課表）。

### 4. 產生印領清冊
1. 在 `admin.html` 選月份、核對後下載當月 JSON。
2. 與 `generate_voucher.py` 放同一資料夾，需要 `pip install python-docx openpyxl`。
3. 另外自備印領清冊 Excel 範本（本分享版**不含**，因為原檔含真實教師姓名），欄位請依腳本內讀寫的儲存格調整。
4. 執行 `python generate_voucher.py`，依提示輸入日薪等資料。

## ⚠️ 安全說明（請務必閱讀）

這個系統為了「老師免登入」，在安全上做了取捨，部署前請知道：

- **`teacher.html` 一定要公開**，所以後端網址會被看到。
- 後端**不需金鑰就能做的事**：讀取課表（`timetable`）、讀取代課教師姓名清單、重複檢查、**送出表單（寫入）**。
  - 代表任何拿到後端網址的人都可以：讀到全校課表、對你的試算表送出假資料。
  - 金額、請假教師、各月明細等敏感資料**都需要金鑰**，外人讀不到。
- 因此：
  - 不要把真實的後端網址、`SECRET_KEY` 寫進公開 repo 或公開文件。
  - 核銷後台 `admin.html` **不要放上網**，只在本機開啟。
  - 試算表分享設定不要設成「知道連結的人都能檢視」。
  - 月底核銷前要人工檢查有無異常筆數。
- 若不能接受上述風險，可在 `doPost` 加上校內口令或限制，再自行調整。
